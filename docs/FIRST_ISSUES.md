# Suggested first issues

Create these as GitHub Issues after publishing the repository. Check the repository first so you do not create duplicates.

1. **[Good first issue] Add a linear search solution**
   - Add `solutions/arrays/linear_search.py`.
   - Include a short explanation and complexity.
   - Add tests for found and missing values.

2. **[Good first issue] Add a factorial solution**
   - Add an iterative factorial implementation.
   - Define behavior for zero and negative input.
   - Add tests.

3. **[Good first issue] Improve the getting-started guide**
   - Review README setup instructions.
   - Suggest clearer wording for Windows and Linux/macOS.

4. **[Good first issue] Add a binary search solution**
   - Document the sorted-input requirement.
   - Test empty input, one element, and missing target.

5. **[Help wanted] Add a linked-list example**
   - Keep the implementation beginner-friendly.
   - Include tests for empty and non-empty lists.

6. **[Good first issue] Add edge cases to string solutions**
   - Add useful tests and explain the expected behavior.

## Suggested labels

`good first issue`, `help wanted`, `bug`, `documentation`, `enhancement`, `needs review`, `duplicate`, `invalid`.
